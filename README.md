# JupyterLite

[![lite-badge](https://jupyterlite.rtfd.io/en/latest/_static/badge.svg)](https://jupyterlite.github.io/demo)

JupyterLite can be used to run Jupyter notebooks directly in your browser without
- any server-side components, and
- any installation.

It comes with many useful Python packages pre-installed, e.g.,
- `numpy`
- `pandas`
- `matplotlib`
- `scipy`
- ...

This is useful in a training setting since only web browsers are required.
